Sincronización multi-dispositivo (Firebase)

      

        


        

          
          
          

            
            
          

          

            
            
            
          

          

            ¿Cómo configurarlo? (5 minutos)
            
    
              
  1. Entrá a console.firebase.google.com y creá un proyecto.
    2. 
              
  2. En Compilación → Realtime Database creá una base de datos.
    3. 
              
  3. En Compilación → Authentication → Sign-in method (Método de acceso) habilitá Correo electrónico/contraseña.
    4. 
              
  4. En Authentication → Users tocá Agregar usuario y creá el usuario del taller (email + contraseña). Ese mismo usuario se usa en los 2 celulares y la PC.
    5. 
              
  5. En Realtime Database → Reglas pegá estas reglas seguras (solo usuarios autenticados pueden leer/escribir) y publicá:
                
    {
  "rules": {
    "talleres": {
      "$codigo": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
    
              
    6. 
              
  6. En Configuración del proyecto → Tus apps agregá una app Web y copiá el firebaseConfig.
    7. 
              
  7. Pegalo acá con el mismo código de taller, el email y la contraseña del usuario creado, y tocá Conectar.
    8. 
              
  8. La sesión queda guardada en el dispositivo: no se vuelve a pedir la clave hasta que toques Cerrar sesión.
    9.
